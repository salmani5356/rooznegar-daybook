# روزنگار — بسته آماده بارگذاری در GitHub Pages

محتویات این بسته:
- `index.html`: نسخه اصلاح‌شده برنامه
- `manifest.webmanifest`: مشخصات نصب وب‌اپ
- `service-worker.js`: کش پوسته برنامه برای استفاده آفلاین اولیه
- `README-UPLOAD.txt`: راهنمای بارگذاری

## روش بارگذاری
۱. از مخزن GitHub یک نسخه پشتیبان بگیر.
۲. این چهار فایل را در ریشه مخزن، کنار فایل‌ها و پوشه‌های فعلی قرار بده.
۳. پوشه `assets/` موجود در مخزن را حذف یا جایگزین نکن.
۴. وجود فایل‌های `assets/journal-vignette.svg` و `assets/daily-1.svg` تا `assets/daily-5.svg` را بررسی کن.
۵. تغییرات را در شاخه `main` ثبت کن و منتظر انتشار GitHub Pages بمان.

## نکته‌های مهم
- تصاویر پوشه `assets/` در این بسته نیستند؛ تصاویر فعلی مخزن باید حفظ شوند.
- Service Worker پوسته و فایل‌های محلی را برای دسترسی آفلاین اولیه cache می‌کند؛ همگام‌سازی Supabase بدون اینترنت انجام نمی‌شود.
- قبل از اعلام انتشار نهایی، ورود/خروج، ذخیره یادداشت، افزودن/حذف کار و همگام‌سازی دو دستگاه را با یک حساب واقعی آزمایش کن.
- پیش از جایگزینی فایل‌ها از مخزن و اطلاعات برنامه نسخه پشتیبان بگیر.
