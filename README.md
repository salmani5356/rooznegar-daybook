# روزنگار | دفتر روزهای تو

دفترچه‌ی روزانه‌ی فارسی (PWA) با تقویم شمسی، یادداشت و چک‌لیست برای هر روز، ثبت حال‌وهوا، آرشیو روزها، جست‌وجو، پشتیبان‌گیری/بازیابی و تصویر آبرنگی و جمله‌ی انرژی‌بخش روزانه.

- داده‌ها به‌صورت پیش‌فرض در مرورگر همین دستگاه ذخیره می‌شوند.
- با ورود با ایمیل و رمز (Supabase) یادداشت‌ها و کارها بین دستگاه‌ها همگام می‌شوند. حال‌وهوا فعلاً فقط محلی است.
- فونت وزیرمتن و کتابخانه‌ی Supabase داخل خود پروژه هستند (`assets/fonts`، `assets/vendor`) و برای اجرا به سایت بیرونی نیاز نیست.
- برای نصب و کارکرد آفلاین باید روی HTTPS (مثل GitHub Pages) منتشر شود.

## فایل‌ها
| فایل | کاربرد |
| --- | --- |
| `index.html` | کل برنامه |
| `service-worker.js`، `manifest.webmanifest` | نصب‌پذیری و کش آفلاین |
| `assets/` | تصاویر روزانه، فونت، کتابخانه‌ها |
| `privacy.html` | سیاست حریم خصوصی |
| `android/` | پوسته‌ی WebView که نسخه‌ی منتشرشده روی GitHub Pages را باز می‌کند |
| `.github/workflows/build-apk.yml` | ساخت APK آزمایشی (Debug) از پوشه‌ی `android/` |

## نکته‌ها
- پروژه‌ی اندروید فقط آدرس `https://salmani5356.github.io/rooznegar-daybook/` را باز می‌کند؛ پس با تغییر وب نیازی به ساخت دوباره‌ی APK نیست.
- ورود با **ایمیل و رمز عبور** است (بدون نیاز به باز کردن لینک؛ داخل APK هم کار می‌کند). در Supabase → Authentication → Sign In / Providers → Email می‌توانی **Confirm email** را خاموش کنی تا ساخت حساب بدون ایمیل تأیید انجام شود. حساب‌های قدیمی که با لینک ساخته شده‌اند، یک بار از داخل برنامه (کارت حساب ابری) رمز تعیین می‌کنند.
- در Supabase باید RLS فعال و Redirect URL آدرس GitHub Pages مجاز باشد. کلید `service_role` را هرگز در فایل‌ها نگذار.
