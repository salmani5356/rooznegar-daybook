# روزنگار لوکس – نسخه‌ی تصویر روزانه
این نسخه پنج تصویر طبیعتِ همراه برنامه دارد و بر اساس تاریخ انتخاب‌شده، تصویر و جمله‌ی انرژی‌بخش روز را تغییر می‌دهد. تصاویر داخل بسته هستند و برای نمایش به اتصال اینترنت نیاز ندارند.

امکانات: تقویم شمسی، صفحه‌ی مستقل هر روز، یادداشت، چک‌لیست، ثبت حال‌وهوا، آرشیو، جست‌وجو، پشتیبان‌گیری/بازیابی، طراحی واکنش‌گرا و PWA.

اطلاعات در مرورگر همین دستگاه ذخیره می‌شود. همگام‌سازی ابری و قفل رمزدار در این نسخه فعال نیست. برای نصب و کارکرد آفلاین، فایل‌ها را روی HTTPS مانند GitHub Pages منتشر کنید.
